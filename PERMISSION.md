# Game Server Permission Nodes

Staff and admin commands on Bukkit/CubingPaper servers use `speedcubing.command.server.<command>`.

LuckPerms must be installed on each game server. Console execution is allowed.

## Wildcards

```text
speedcubing.command.server.*
speedcubing.command.*
```
